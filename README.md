# lab1
Lab 01: Data Representation in C
Виконав: Артем Гілевич

1. Завдання 1. Розміри типів даних (types.c)
- char: 1 bytes (8 bits)
- short: 2 bytes (16 bits)
- int: 4 bytes (32 bits)
- long: 8 bytes (64 bits)
- long long: 8 bytes (64 bits)
- float: 4 bytes (32 bits)
- double: 8 bytes (64 bits)
- void *: 8 bytes (64 bits)

2. Завдання 2. Decimal, Hexadecimal, Binary (representations.c, binary.c)
- 10 -> Hex: 0x0A, Binary: 00001010
- 65 -> Hex: 0x41, Binary: 01000001
- 127 -> Hex: 0x7F, Binary: 01111111
- 255 -> Hex: 0xFF, Binary: 11111111
- 256 -> Hex: 0x0100
- 1024 -> Hex: 0x0400

3. Завдання 6. Переповнення unsigned integer (overflow.c)
- Прогноз: При додаванні 1 до 255 відбудеться переповнення і значення скинеться до 0.
- Результат: 255 + 1 = 0.

4. Завдання 7 та 8. Порядок байтів (memory.c)
- Очікували Little-endian.
- Фактичний результат у пам'яті для 0x12345678: байти розташовані від молодшого до старшого (0x78, 0x56, 0x34, 0x12), що підтверджує використання Little-endian на x86-64.

5. Контрольні питання
1. Що таке біт і байт? Найменша одиниця інформації (0 або 1) та блок з 8 бітів.
2. Скільки значень у n бітах? 2^n.
3. Діапазон 8-бітного unsigned: від 0 до 255.
4. Діапазон 8-бітного signed (two's complement): від -128 до 127.
5. Чому hex зручний? Кожна шістнадцяткова цифра дорівнює рівно 4 бітам.
6. 11111111 як uint8_t це 255, а як int8_t це -1.
7. Після збільшення uint8_t зі значенням 255 стається переповнення (значення стає 0).
8. У пам'яті для символу 'A' зберігається його числовий код 65.
9. Endianness — це порядок байтів багатобайтових чисел у пам'яті.
10. Досліджувана система використовує Little-endian.
11. sizeof(int) повертає розмір типу int у байтах (4 байти).
12. Одні й ті самі біти інтерпретуються по-різному залежно від типу даних і контексту.

6. Підсумок
Експериментально досліджено представлення даних у пам'яті, роботу з бітами, межі беззнакових типів та порядок байтів (Little-endian) за допомогою мови C та GCC.
